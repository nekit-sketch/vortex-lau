# Vortex Launcher
Сборка: push в GitHub → Actions → артефакт `vortex-launcher-debug-apk` (debug-ключ подставляется Gradle автоматически). Gradle wrapper не нужен: workflow ставит Gradle 8.7 через gradle/actions/setup-gradle.
Локально: Android Studio → Build APK(s).

## Что реализовано
- Классический режим: огромные часы, приветствие + погода (Open-Meteo, без ключа), док-капсула (liquid glass), остров, мини-плеер.
- Gaming (PS5): вкладки, карусель с закреплением выбранного слева, баннер из иконки приложения, кнопка «Играть/Открыть», блок «Запусков / Тип».
- Центр управления: плитки Power, Wi-Fi, Recent Apps, Звук, Таймер сна, круглые кнопки. Морфинг скинов — раскрытие кругом из центра.
- Скин хранится в DataStore (K.SKIN) и в профиле; при старте `VortexRoot` читает его и открывает тот же режим. Выбор профиля при загрузке ТВ скин не сбрасывает.
- Анимации: онбординг (aurora, stagger), запуск приложений (ActivityOptions scale-up), возврат на главный (windowAnimationStyle + spring).

## Ограничения Android
- Перезагрузка: только Device Owner: `adb shell dpm set-device-owner com.vortex.launcher/.system.AdminReceiver`. Выключение ТВ без системных прав недоступно.
- Таймер сна: блокирует экран через DevicePolicyManager.lockNow — нужно выдать «Администратор устройства» (Настройки → Система).
- Недавние приложения: UsageStats, нужен спец. доступ. Плеер: «Доступ к уведомлениям».
- Свайп вниз для Центра управления не реализован (управление только пультом): открывается кнопкой на острове/аватаре.
- Блок достижений PS5 заменён статистикой запусков (у обычных приложений нет трофеев).
